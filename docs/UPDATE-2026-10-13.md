## Scope and evidence

This pass refreshed the current directory, framework guide, community guide, skills catalog, related lists, local model tools, model setup guide and contribution guide. It added a public-source harness research guide and original friendly agent artwork with a reusable prompt.

The initial discovery pass extracted 181 unique GitHub URL candidates from the former root documents plus planned additions. GitHub GraphQL resolved 163. The other 18 included placeholder examples, product or topic pages, mistyped names and unresolved projects. MLX LM was queried separately after the local serving guide was updated.

The final current inventory contains **125 distinct repository URLs**, all resolved through GitHub metadata. The [JSON snapshot](data/catalog-2026-10-13.json) records canonical names, archive flags, descriptions, default-branch revisions, license fields and the latest published release field. All repositories in that current inventory were non-archived at capture.

Metadata was retrieved through the authenticated GitHub CLI, in GraphQL batches of 40. It establishes repository state on the check date. It does not prove the listed capabilities, security, billing, deployment readiness or the behavior of executable examples.
